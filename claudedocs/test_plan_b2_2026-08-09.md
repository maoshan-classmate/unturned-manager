## 1. 测试策略

三层验证，逐层递进：

```
单测（单元）   →  契约/e2e（集成）   →  Linux 真机（端到端）
  Windows          Windows              Linux（Sprint 5）
  纯逻辑/fs/crypto  API 形状 + 真写目录  真实进程 + 真实服务端
```

- **底层逻辑**：Windows 开发环境覆盖逻辑层 100%——本次全部代码改动都在 Windows 可单测。
- **顶层设计**：Linux 真机只验 3 条「进程/网络真源」链路（真实 U3DS 关停语义 / 崩溃自愈 / A2S 真服务端）。
- **验收铁律**：`promise 能跑 ≠ 真机能跑`——标 🔴 Linux 的用例必须实机跑通才算 Done，不以前端/单测全绿代替。

## 4. 前端 UI 预期效果（B2 前端改动可视化体现）

> B2 前端可见改动集中在 `ServerSetupPage` / `CreateServerDialog` / `DashboardPage` / `useServer`。本节描述**用户操作路径的预期 UI 表现**，作为 e2e 与人工验收的视觉基准。

### 4.1 改前 vs 改后 行为对比

| 用户操作 | 改前（B2 前） | 改后（B2 后） | 用户可感知差异 |
|---|---|---|---|
| 创建实例 | 纯前端本地——只改内存数组，**刷新页面实例消失** | 真实 `POST /servers` → 落盘目录 + K-V 凭证 → `refresh` 拉回 | 刷新后实例仍在；重启后端仍扫描到 |
| 删除实例 | 纯前端本地假动作——只从数组移除，**目录/凭证原封不动** | 真实 `DELETE /servers/:id` → 删目录 + 删凭证 + unregister | 目录真删、不可恢复；ConfirmDialog 文案明确警告 |
| 创建弹窗 RCON 字段 | 采集 `rconPassword` 但**丢弃** | `rconPassword` 接上 + 新增 `openModCredential` 字段 | 创建时填的凭证真正生效，重启不丢 |
| 实例端口/名称 | 读 DB 缓存行（可能过期） | Commands.dat 实时解析（目录真源） | Dashboard/侧栏显示的端口是配置真值 |
| 实例状态 | DB 持久化（陈旧） | 目录扫描 + A2S 探活实时 | 重启面板后状态反映真实在线情况 |

### 4.2 创建流程——预期 UI 表现（页面：`/server-setup`）

```
① 点侧栏「新建」           → 弹出 CreateServerDialog（标题「创建新实例」）
② 填表（7 字段）           → ServerID / 名称 / 游戏端口 / Owner SteamID64 / 安装目录
                              / RCON 密码(可选) / 【新增】OpenMod RCON 凭证「SteamID:密码」
③ 点「创建」               → 按钮变「创建中...」（Save 图标 pulse，disabled）
④ 成功                    → toast「实例「MyServer」已创建」→ 弹窗关闭 → 表单 reset
⑤ 侧栏                    → 新增该实例行：状态圆点 + 名称 + 「STOPPED」副标签
⑥ 失败（如 ServerID 冲突 409）→ toast 错误文案，弹窗保持打开，已填内容不丢
```

**涉及组件**：`CreateServerDialog.tsx`（表单 + loading 态 + toast）、`ServerSetupPage.tsx`（侧栏 `servers.map` 渲染）、`useServer.addServer`（POST + refresh）。

### 4.3 删除流程——预期 UI 表现（页面：`/server-setup`）

```
① hover 侧栏实例行        → 垃圾桶图标 opacity-0 → 100 淡入（group-hover）
② 点垃圾桶               → 弹出 ConfirmDialog：标题「删除实例」
                            正文「确定删除实例「X」吗?将同时删除其 Servers/<id> 目录
                            与所有配置(不可恢复)。」
③ 点「删除」(danger)      → 按钮 loading（deleting=true）
④ 成功                    → toast「实例「X」已删除」→ 侧栏该行消失
⑤ 删的是当前选中实例       → 自动 navigate 到下一个剩余实例（无则回 /_default/server-setup）
⑥ 失败                    → toast.error，弹窗关闭
```

**涉及组件**：`ServerSetupPage.handleDelete`（`await removeServer` + catch + finally 关闭）、`ConfirmDialog`（variant=danger + loading）、`useServer.removeServer`（DELETE + refresh）。

### 4.4 Dashboard 预期效果（页面：`/` 或 `/test-server`）

- 实例卡/统计区显示 **`{id} · 端口 {gamePort}`**（`DashboardPage.tsx:164`）——端口为 Commands.dat 解析真值。
