# 实机 2 bug 修复闭环（2026-08-13）

Linux UAT 实机暴露 2 个契约不一致 bug，诊断 → 修复 → 单测 → 双 commit 全闭环。

## Bug 1: checkUpdate 永远显示「有新版本可用」

- 根因：`SteamCmdManager.checkUpdate` 只 parse 远端 Steam 仓库 buildid 塞进 `latestVersion`，**从未对比本地** `steamapps/appmanifest_1110390.acf` 的 buildid → latestVersion 恒 truthy → 前端 U3dsCard truthy 判断永远「有新版本」
- 修复：新增 `readLocalBuildId(installDir)` helper（复用 VdfParser，路径同 U3dsStatusProvider）；本地==远端 → `latestVersion=""`（前端「已是最新」）；本地≠远端 → remoteBuildId；本地缺失 → 兜底 remoteBuildId（未装场景仍可提示安装）；删 nameMatch 死分支兜底
- Commit：`f3a8132`（SteamCmdManager.ts 改 + SteamCmdManager.checkUpdate.test.ts 新增 5 用例）

## Bug 2: Config.txt 保存 400 + 读取为空

- 根因：前端读写用**裸 kv map**形态（`sections["浏览器"].Login_Token = "..."`），后端 schema `ConfigSectionSchema = { name, entries: ConfigEntry[] }` 拒绝 → 400；read 侧解构 `sections["浏览器"].Login_Token` 也读不到（值在 `entries[]` 里）→ 编辑器全空
- 修复：新建 `manager-web/src/pages/configTxtAdapter.ts` 4 helper（`readStringEntry`/`readBoolEntry`/`boolEntry`/`stringEntry`/`buildTxtSections`），ConfigPage 读写两侧走 helper 适配 schema
- Commit：`305b049`（ConfigPage.tsx 改 + configTxtAdapter.ts 新增 + configTxtAdapter.test.ts 新增 17 用例）

## 颗粒度经验（复用）

- **TS 重载不能做运行时类型分支**——`readSectionEntry(isBool: true/false)` 重载在运行时被忽略，`isBool=false` 实际返回 `false` 而非 `''`（单测 1/14 捕获）。拆独立函数 `readStringEntry`/`readBoolEntry`
- **helper 抽独立文件可测**——页面内联 helper 无法单测；抽到页面同级文件（不满足 lib/utils ≥2 模块触发条件时）
- **owner 意识**——前端信任后端 deliver 布尔信号，后端必须做 owner 判断（本地 vs 远端对比），不能让前端拿 truthy 猜
